# EM1 Solver v0.8 – Trinvis udledning

Fem gennemarbejdede testcases med begrundelse for metodevalg, eksplicit substitution og algebra mellem ligningerne.

**Ikke en autonom solver:** Testløsninger er statiske og er mærket som testdata. Import af `em1.desktop.solution.v1` er stadig mulig. Eksisterende JSON-filer uden ekstra felter understøttes fortsat.

Start på Windows med `START_WINDOWS.bat`. Der er ingen ændringer i Codex-repository, databaseplacering eller opstartsmiljø.
