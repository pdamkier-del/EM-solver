EM1 Solver Desktop v1.0.2 – officiel eksamensfacit-reference\n\nUnder Eksamen: vælg eksamensdato og opgave, klik Vis facit. Original PDF vises på korrekt side. PDF åbnes først ved klik, så opstarten ikke forsinkes.\n\nFacit er IKKE automatisk integreret i solverens verifikationsalgoritme. Det bruges som reference til manuel sammenligning og regressionstests. Alle matematiske udtryk skal kontrolleres visuelt.\n\nInstaller som før med SETUP_BACKEND_WINDOWS.bat, start via START_WINDOWS.bat.\n
