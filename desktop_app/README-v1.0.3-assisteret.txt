EM1 Solver v1.0.3 — assisteret modelkorrektion

NYT: Ved not_solved kan du vælge "Ret fortolkning" og angive manglende geometri, radialkoordinat, udstrækning, radius eller tæthed. Valgene sendes til den eksisterende offline backend via dens dokumenterede corrections-API. Ingen facit eller historisk svar bruges til løsningen.

VIGTIGT: Manuelle valg er brugerens forudsætninger og markeres i visningen. Matematiske checks beviser ikke opgavetekstens rigtige fortolkning. Brug kun værdier, der er angivet eller fysisk begrundet.

BEGRÆNSNING: Dette retter ikke backendens generelle autonomi. Python 3.13 og native Windows/Qt er endnu ikke verificeret her. Behold v1.0.2 indtil denne version virker hos dig.
